#Retail Customer Analyzer

## Project Description
Retail Customer Analyzer is a Python-based project used to analyze customer spending data.

## Technologies Used
- Python
- Pandas
- CSV
- VS Code

## Features
1. Load customer data feom CSV file.
2. Calculation mean, median, maximum and minimum spending.
3. Find high-value customers.
4. Display city-wise spending summary.
5. Handle invalid input and missing files.

## How to Run
1. Install Python.
2. Install Pandas using: pip install pandas
3. Run the program: python main.py
